# FlashDreams Python package

This directory contains the installable FlashDreams framework, its package tests, and developer tools. Start with the [quickstart](../docs/src/content/docs/quickstart/index.md), use the [API overview](../docs/src/content/docs/api/index.md) to choose between the inference, demo, and application protocol APIs, and see [CONTRIBUTING.md](../CONTRIBUTING.md) before changing the package.
